# PharmEasy Regional Pulse

A pipeline that cleans a messy monthly order export, computes SQL-verified region-level metrics, flags regions that moved enough to matter, drafts a reviewable narrative and recommendation, routes it through a human approve/edit/reject gate, and presents everything on an interactive dashboard.

## How to run

pip install pandas streamlit plotly

python3 generate_dataset.py
python3 clean_data.py
python3 build_db.py
python3 queries.py
python3 metrics_engine.py
python3 draft_report.py
python3 review_gate.py

streamlit run app.py

## Files

- generate_dataset.py - builds the raw dataset
- clean_data.py - cleans it, includes validate_schema
- data_quality_report.md - maps each fix to a data-quality dimension
- build_db.py - builds pharmeasy.db
- queries.py - JOIN validation and region/month metrics SQL
- metrics_engine.py - flagging and state persistence
- draft_report.py - CII narrative generator
- memo.md - one-page recommendation memo, risk-tagged
- review_gate.py - approve/edit/reject gate, writes audit_log.jsonl
- audit_log.jsonl - generated by review_gate.py
- reliability_checklist.md - safety, validation, critique, sign-off
- app.py - Streamlit dashboard
- presentation_storyline.md - two audience reframings plus pushback Q&A
- README.md - this file

## Cover note

Headline finding: Guntur's sales rose +122.19% from April to May 2026 (Rs 62,442.27 to Rs 138,738.93), the largest region-level swing this quarter, then partially pulled back -28.11% in May-June.

Read in this order:
1. Dashboard (app.py, run with streamlit run app.py) - live data, KPIs, charts, detail table.
2. CII narrative (draft_report.py output, and the dashboard's executive summary) - what the numbers mean, region by region.
3. Memo (memo.md) - the recommendation: don't reallocate Guntur's targets until a manual order-level spot-check confirms the spike is broad-based.
4. Presentation storyline (presentation_storyline.md) - how to defend this finding live, for an executive and for a regional manager, plus pushback Q&A.

Single unverified assumption: that Guntur's May spike reflects genuine demand growth, not a data artifact such as one large bulk order. This has not been checked against Guntur's individual order rows.
